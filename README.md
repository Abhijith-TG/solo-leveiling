# Solo Leveling

A small project I built to make coding feel more rewarding.

The idea is simple: complete coding-related tasks, earn XP, level up, and track your progress like a game. Instead of staring at a huge goal like "become a better developer", you focus on completing small quests and watching your character grow over time.

## Features

* Level and XP system
* Daily coding quests
* Quest completion tracking
* Circular XP progress indicator
* Progress saved with Local Storage
* Daily quest reset

## Why I Built This

I found myself spending more time thinking about coding than actually coding.

I wanted something that would encourage me to open VS Code, complete small tasks, and build momentum every day. So I decided to turn the process into a simple RPG-inspired system.

## Current Quests

* Make a Git commit
* Fix a bug
* Create a React component
* Study for 30 minutes
* Solve a DSA problem
* Write an API endpoint
* Read documentation
* Refactor code
* Push code to GitHub
* Deploy a project
